# Grupo Branding — ARQ-01

## Propósito

Arquitectura de Información interactiva del nuevo portal de Grupo Branding.

## Archivos

- `index.html` — aplicación standalone y fuente del entregable.
- `og-image.png` — imagen de preview social.
- `README.md` — documentación interna.

## Arquitectura

El objeto `blueprint` dentro de `index.html` es la única fuente de verdad del contenido arquitectónico.

## Ejecución

No requiere servidor, npm, build ni framework. Puede abrirse directamente en un navegador.

## Regla de mantenimiento

A partir de esta versión, editar directamente `index.html`. No regenerar mediante Superdesign u otra herramienta de generación visual salvo decisión explícita posterior.

## Publicación

Destinado a GitHub Pages.

## Indexación

El documento utiliza `noindex, nofollow, noarchive`. Mantenerlo mientras sea un entregable de preproducción.
